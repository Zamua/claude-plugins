# clean-copy

A skill for cutting interface copy that shouldn't exist, before polishing what
stays: captions that restate a label, hints that pre-empt a worry the user never
had, warnings left over from a fixed bug.

Use it when writing or reviewing labels, hints, empty states, toasts,
confirmations and button text. On a batch it reports each string as `file:line`
with a rewrite or `cut`, and which rung of its ladder the string failed.
